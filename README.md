# gren-keyboard

Proper type-safe keys and decoders for keyboard events.

See [developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent](
https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent).

This Gren package is based on the Elm packages
[Gizra/elm-keyboard-event](https://github.com/Gizra/elm-keyboard-event) and
[SwiftsNamesake/proper-keyboard](https://github.com/SwiftsNamesake/proper-keyboard).
